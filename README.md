# 🩺 Quick-Cure

> A smart appointment-booking application designed to make finding and scheduling healthcare appointments simpler.

## 🎯 Goal

Quick-Cure explores a cleaner digital flow for patients who need to discover providers and book appointments without unnecessary friction.

## ✨ Planned / Current Focus

- 🗓️ Appointment booking flow
- 👨‍⚕️ Doctor/provider discovery
- 👤 Patient-focused experience
- 📱 Responsive application interface
- 🔧 Extensible application structure

## 📁 Repository

The main application lives inside the [QuickCure](./QuickCure) directory.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sanyukt63/Quick-Cure.git
cd Quick-Cure
```

Open the `QuickCure` directory and follow the setup instructions provided by the application files.
