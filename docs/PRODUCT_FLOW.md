# Appointment Flow

The core Quick-Cure workflow should stay simple for patients.

1. Discover a provider or service.
2. Review available appointment information.
3. Select a suitable slot.
4. Confirm the booking details.
5. Show a clear confirmation state.
6. Make the appointment easy to find or manage later.

## UX principles

- Keep the primary action obvious.
- Minimize unnecessary form fields.
- Show validation errors next to the affected field.
- Preserve entered information when validation fails.
- Make booking status understandable without relying on color alone.
